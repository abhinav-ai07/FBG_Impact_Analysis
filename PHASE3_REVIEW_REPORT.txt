1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
This report provides an independent, rigorous review and validation of the
`phase3-preprocessing` branch for the FBG_Impact_Analysis repository.
The objective of Phase 3 is to ingest raw FBG wavelength/strain time-series data,
clean and baseline-correct the signals, compute wavelength shifts, and apply noise
reduction/filtering techniques to produce signals suitable for Phase 4 impact
detection.

Core algorithmic modules implemented in `src/` (loading, cleaning, baseline
subtraction, wavelength shift, Butterworth filtering, Savitzky-Golay filtering,
median filtering, and moving average filtering) are mathematically sound and
execute effectively. When supplied with the raw dataset files, the processing
pipeline achieves substantial noise reduction (30% to 67% reduction in baseline
standard deviation) while preserving genuine impact profiles (>96% amplitude
retention on sustained impacts) with zero phase distortion via zero-phase forward-
backward filtering (`filtfilt`).

However, the branch in its current state CANNOT be approved for merge due to
one CRITICAL operational defect, one HIGH-severity usability issue, and a MEDIUM-
severity packaging omission:
  1. CRITICAL: `main.py` hardcodes the raw data path to `data/raw` (which does
     not exist in the repository) instead of `raw_data`. Consequently, executing
     `python main.py` out-of-the-box finds 0 datasets and performs 0 operations.
  2. HIGH: `src/visualization/plots.py` invokes blocking `plt.show()` calls
     inside the main batch loop (48 blocking GUI windows across all channels/datasets),
     freezing automated execution and failing to save any plot artifacts to disk.
  3. MEDIUM: `requirements.txt` is completely empty (0 bytes), preventing
     reproducible environment setup.

3. PHASE 3 COMPONENTS FOUND
--------------------------------------------------------------------------------
The following modular components were identified in `src/`:

1. `src/io/data_loader.py`:
   - `load_fbg_data(file_path)`: Tab-separated table reader with column naming.
2. `src/io/save_processed_data.py`:
   - `save_filtered_signals(time, raw_signal, filtered_signals, experiment_name, channel)`:
     Saves CSV per channel containing raw wavelength shift and 4 filtered variants.
3. `src/preprocessing/cleaning.py`:
   - `clean_signal(signal)`: Coerces numeric data, performs linear interpolation,
     and applies `bfill()` / `ffill()`.
4. `src/preprocessing/baseline.py`:
   - `calculate_baseline(signal, baseline_samples)`: Calculates mean of initial N samples.
   - `baseline_correct(signal, baseline_samples)`: Subtracts scalar baseline.
5. `src/preprocessing/wavelength.py`:
   - `calculate_wavelength_shift(signal, baseline)`: Computes Delta_lambda = lambda - lambda_0.
6. `src/preprocessing/preprocessing_pipeline.py`:
   - `preprocess_signal(signal, baseline_samples)`: Orchestrates cleaning, baseline,
     and wavelength shift.
7. `src/filtering/butterworth.py`:
   - `butterworth_filter(signal, cutoff, sampling_frequency, order=4)`: Low-pass
     Butterworth filter using `scipy.signal.filtfilt` (zero phase distortion).
8. `src/filtering/median.py`:
   - `median_filter(signal, kernel_size=5)`: Median filter using `scipy.signal.medfilt`.
9. `src/filtering/moving_average.py`:
   - `moving_average(signal, window=5)`: Centered moving average using pandas `.rolling()`.
10. `src/filtering/savitzky_golay.py`:
    - `savitzky_golay_filter(signal, window=11, polyorder=3)`: Polynomial smoothing
      using `scipy.signal.savgol_filter`.
11. `src/filtering/filter_comparison.py`:
    - `apply_all_filters(signal, sampling_frequency)`: Applies all 4 filter variants.
12. `src/analysis/noise_analysis.py`:
    - Functions for noise STD, RMS, peak amplitude, peak timing, peak preservation,
      and noise reduction percentage in baseline regions.
13. `src/visualization/plots.py`:
    - Matplotlib routines for raw signals, wavelength shift, and filter comparisons.
14. `src/config.py`:
    - Constants for sampling frequency, baseline sample count, and channel mappings.

5. PREPROCESSING VALIDATION
--------------------------------------------------------------------------------
- Operations Implemented:
  1. Data cleaning / coercion: `pd.to_numeric(..., errors='coerce')`
  2. Linear interpolation for missing points: `.interpolate(method='linear')`
  3. Edge filling: `.bfill().ffill()`
  4. Baseline extraction: Mean of first `BASELINE_SAMPLES` (100 samples = 2.0s).
  5. Static baseline subtraction / Wavelength shift: Delta_lambda = lambda - lambda_0
- Operations NOT implemented:
  * Polynomial detrending / high-pass baseline tracking (assumes static baseline).
  * Dynamic resampling / anti-aliasing.
  * Signal normalization (e.g. min-max or z-score) - intentionally omitted to
    preserve physical wavelength units (nm/pm).
- Verification Result:
  * Preprocessing runs reliably on all datasets without numeric exceptions.
  * Note: `preprocess_signal` redundantly computes `baseline_correct` and
    `calculate_wavelength_shift` (which perform identical operations).


6. NOISE REDUCTION VALIDATION
--------------------------------------------------------------------------------
- Techniques Employed:
  * Low-pass Butterworth (cutoff = 5 Hz, effective order = 8 via forward-backward filtfilt)
  * Savitzky-Golay (window = 11 samples / 0.22s, polynomial order = 3)
  * Moving Average (window = 5 samples / 0.10s, centered)
  * Median Filtering (kernel_size = 5 samples / 0.10s)
- Consistency:
  * Applied identically across FBG1, FBG2, and FBG3 channels.
- Performance Across Baseline Regions:
  * Butterworth: 47.6% to 67.2% reduction in baseline noise STD.
  * Savitzky-Golay: 45.9% to 64.5% reduction in baseline noise STD.
  * Moving Average: 48.6% to 64.7% reduction in baseline noise STD.
  * Median: 29.9% to 54.4% reduction in baseline noise STD.
- Verification Result:
  * Noise reduction executes cleanly and reduces high-frequency baseline jitter
    from ~4.5 pm STD to ~1.7 pm STD on FBG1, and ~1.4 pm STD to ~0.55 pm STD on FBG2.


7. FILTERING VALIDATION
--------------------------------------------------------------------------------
1. Butterworth Filter:
   - Parameters: cutoff = 5 Hz, order = 4, fs = 50 Hz (Nyquist = 25 Hz).
   - Implementation: `scipy.signal.butter(4, 0.2, btype='low')` + `filtfilt(b, a, signal)`.
   - Assessment: Zero-phase forward-backward filtering eliminates time delays.
     No ringing or boundary artifacts observed on continuous records.
2. Savitzky-Golay Filter:
   - Parameters: window = 11 (0.22s), polyorder = 3.
   - Implementation: `scipy.signal.savgol_filter`.
   - Assessment: Maintains curvature of transient peaks while smoothing random noise.
3. Moving Average:
   - Parameters: window = 5, centered = True, bfill/ffill for edge boundaries.
   - Assessment: Good basic smoothing, but expects `pd.Series` input.
4. Median Filter:
   - Parameters: kernel_size = 5.
   - Implementation: `scipy.signal.medfilt`.
   - Assessment: Rejects single-sample non-physical spike artifacts effectively.

    glitches rather than physical structural impacts, are appropriately attenuated

- Phase / Time Shifts:
  * Because Butterworth uses `filtfilt` and moving average uses `center=True`,
    zero time shift is introduced across the entire pipeline.
- Artificial Peaks / Ringing:
  * No spurious oscillatory ringing or artificial peaks were detected in baseline
    or post-impact recovery zones.
